好友與旅行

連線功能是選用的：不登入、沒網路，毛孩照常養，什麼都不會上傳。登入後可以雲端存檔、加好友，讓毛孩去朋友家玩。

打開方式：右鍵 → 👥 好友・客人貓（或 ⚙ 設定 → ☁ 帳號），會打開「☁ 連線」視窗。

帳號與雲端存檔

不用密碼登入

輸入信箱 → 收到驗證碼 → 輸入就登入。第一次用的信箱會自動建立帳號；同一台電腦之後會自動續登入。

雲端存檔

打開 DeskCat、每 10 分鐘、關掉時同步；另一台電腦有比較新的進度，會先問你要不要換過來（換之前會先備份）。同一個帳號同時只在一台電腦連線，換電腦時會先把舊電腦的進度存好再接手。

第一次登入

可以選「帶入目前的毛孩」或「重新開始」；沒登入時養的毛孩會保留，可以在帳號頁切換。

客人貓與好友互動

好友的貓來你家玩

自然發生

成為好友後，好友的貓偶爾會來玩一陣子再回家，頭上掛著橘色名牌。可以摸牠、餵牠，右鍵「請牠回家」。客人貓不算進你的貓、存檔，也不會改到朋友那邊的進度。

💌 明信片

好友的貓來玩、回家時，自動寄一張明信片給牠的主人：玩了多久、被摸幾次、跟誰疊著睡…收到的在「📬 信箱」。

🎁 每日小禮物

每天可以送每位好友一次；對方下次打開時，禮物盒從天上掉下來，點開拿友情點數。

🧳 去朋友家住一晚

選朋友、住 2～24 小時。出門期間牠不在你的桌面上；回來時跳出旅行日記、叼著伴手禮。可以提早叫牠回家。

🐾 貓咪動態

撞成一團、疊羅漢崩塌、出門回來…有趣的事自動分享給好友，一天最多 3 則，好友可以按 🐾。可以在設定關掉。

🤝 合作週挑戰

自己＋好友這週一起打字＋點擊，到目標大家都能領一次友情點數。只傳「按了幾下」。

💛 友情點數

好友互動的獎勵，存在伺服器上、跟罐罐分開，帳號頁可以看餘額和紀錄。現在先累積，之後會開放兌換。

好友互動不用一直連線：打開 DeskCat 時、之後每 10～30 分鐘才跟伺服器同步一次。刪好友、封鎖之後就不能互動。

設定與常見問題

毛孩擋到我了。

點工具列右下角的小貓，可以全部藏起來，再點一次就回來。只想讓某一隻休息，在毛孩管理按「隱藏」。

會不會記錄我打了什麼字？

不會。程式只計算「按了幾下」，不記錄按了哪些鍵。沒登入時，唯一會連網路的是檢查更新：只去 GitHub 問最新版本號、下載新版，不會傳出你的任何資料。

貓都待在工作列上，不跳上視窗？

最大化的視窗上緣太靠近螢幕頂端，貓站不上去，把視窗縮小一點就好。右鍵 → ⚙ 設定 → 🩺 回報問題 →「顯示貓可以站的地方」，綠線就是貓能站的地方。

點了牠，牠卻沒反應／一直不做某個動作？

很多反應看個性、年齡、精力和時間：高冷的比較不理你，中午比較愛睡；短時間點太多下牠會生氣一陣子。品種的小習慣和互動也是「偶爾」發生，不會每次都出現。

開機自動打開 DeskCat？

⚙ 設定 →「開機自動啟動」打勾。DeskCat 已經開著時再開一次，不會多一群貓，會跳通知「DeskCat 已經開著了」。

一定要登入嗎？

不用。不登入照常養毛孩、存罐罐、買家具；只有雲端存檔、好友、客人貓這些連線功能需要登入。

隱藏毛孩和刪除有什麼不同？

「隱藏」是讓牠去休息，資料都保留，隨時可以再啟用。不想用 DeskCat 了，結束程式後刪掉整個資料夾即可。

換電腦要怎麼搬？

把整個資料夾複製過去就好，毛孩都在 player_data 資料夾。也可以用 ⚙ 設定 → 💾 存檔 →「匯出存檔…」／「匯入存檔…」；登入的話雲端存檔也會跟著走。

不想自動更新？

右鍵 → ⚙ 設定 → ⬆ 更新 →「不要檢查更新」。要更新時再到下載頁下載新的 zip，把 DeskCat.exe 覆蓋舊的就好（player_data 不要刪）。

出問題了怎麼辦？

右鍵 → ⚙ 設定 → 🩺 回報問題 →「複製診斷資訊」，把內容貼給開發者。診斷資訊只有程式狀態和視窗位置，沒有視窗標題或打字內容。

⚙ 其他設定

吃飯時間、你的生日、聊天頻率（話多／正常／安靜／不聊天）、活潑程度、狗叫頻率（不叫／偶爾／常常）、分享貓咪動態、開機自動啟動、更新方式、存檔匯出匯入。
